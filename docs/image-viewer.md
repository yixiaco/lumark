> 更新：2026-11-02。模块位置：`crates/lumark-ui/src/app/view/image_viewer_window/`。

## 交互

| 操作 | 行为 |
|---|---|
| 滚轮 | 指数缩放 0.05–16×，**以光标为锚点**（`anchored_pan`） |
| 左键拖拽 | 平移图片（`fit` 模式禁止拖拽） |
| 适应窗口 | 重置 fit/zoom/pan |
| 100% | 缩放 1× 并清零平移 |
| `−` / `+` | 工具栏按钮，IconPark `zoom-out.svg` / `zoom-in.svg` |
| 左转/右转 | 生成旋转后的临时文件（不修改原图） |

缩放锚点公式：

```
pan' = pan + (1 - new_zoom / old_zoom) × (cursor - canvas_center - pan)
```

画布中心按标题栏 38px、工具栏约 36px、状态栏 26px 近似计算。

## 图片处理

- 静态 JPEG/PNG 读取 EXIF Orientation，必要时生成校正后的临时 PNG；
- 动图/SVG 不做方向校正，避免破坏动画/矢量渲染；
- SVG 通过 `width/height` 或 `viewBox` 预检尺寸；
- 所有临时文件在窗口关闭时删除；
- 图片只读，不写回原文件或归档。

## 测试

- EXIF 方向 6 宽高互换；
- 无 EXIF 保持原文件；
- 左右旋转临时文件宽高；
- 显示名优先资产名；
- 滚轮方向/上下限；
- 光标锚点 3 组断言；
- UI 集成：PNG、EXIF 旋转图片打开，旋转/重置。

## 限制

- 画布中心为布局近似值（未接入精确元素 bounds），极端窗口尺寸下锚点可能有数像素偏差；
- 不支持多图/缩略图列表；
- 超大图依赖 GPUI 解码，未做分块/瓦片。
